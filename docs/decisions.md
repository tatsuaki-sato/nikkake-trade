# 意思決定ログ

コードやREADMEを見ただけでは分からない「なぜこうしたか」を残す場所。新しく閾値・仕様・依存関係を変えたら、変えた本人が一番よく理由を覚えている今のうちに追記する。

古い順ではなく **新しい決定を上に追記**(最新を読めば済むように)。

## テンプレート

```markdown
## YYYY-MM-DD: <一言で何を決めたか>

**背景**: なぜこれを検討することになったか
**決定**: 何をどうしたか
**代替案**: 検討したが採らなかった案(あれば)
**見直す条件**: どうなったら再検討すべきか(あれば)
```

## 2026-08-22: ウォッチリストの一元化と J-Quants API の導入 (v2設計 Phase 0-1)

**背景**: 「銘柄が循環しない」問題の調査で、(1) テーマスクレイパーの取得先 `kabutan.jp/theme/` が404で常に固定フォールバックが返っていた、(2) 12銘柄が3ファイルに重複ハードコードされ循環機構が存在しない、(3) `Close.diff()` の疑似ATRが真のATRの約半分で損切り幅が意図より狭かった、ことが判明。
**決定**:
- テーマ発掘を実在する株探ランキング3本(活況銘柄/過去1ヶ月上昇率/年初来高値、東証プライム)に置換。全取得失敗時のみ固定リストにフォールバックし、その場合はシグナル登録をスキップ+通知に明示。
- ウォッチリストを `common/watchlist.py` に一元化(Supabase `watchlist` テーブル → `data/watchlist.json` → コード内デフォルトの順でフォールバック)。銘柄は `tier: core/rotation` を持ち、core は将来の自動循環の対象外。
- データ基盤として J-Quants API V2 (JPX公式) を導入(`common/market_data.py`、`JQUANTS_API_KEY`)。Freeプランは12週遅延のためユニバース選定・ファクター計算・バックテスト専用。当日価格は引き続き yfinance。
- ATRは `quant_math.calculate_atr`(High/Low使用)に統一。
**代替案**: 全上場銘柄の毎日フルスキャン(センチメント等のスクレイピングが銘柄毎に走る現設計では非現実的)、スクレイピングsoースのみでの循環(サイレント故障の再発リスク)。
**見直す条件**: Phase 2 のバックテストで週次ローテーションの優位性が出なければ、固定リスト+閾値調整に戻す。J-Quants Free の1年期限が切れる前(2027年夏)に Light 契約可否を判断。

## 2026-08-25: apply=True で運用開始 — ただし「投資戦略」ではなく「スキャン候補プールの循環」として

**背景**: 前エントリで apply=True を見送ったが、オーナーから「候補を入れ替えていくならあり」との判断。整理すると、フルバックテストが反証したのは「ローテーション銘柄を**全部買う戦略**」であり、実運用のウォッチリストは買うリストではなく **daily_scanner / trend_predictor のスキャン候補プール**。実際のシグナルは従来どおり70点のクオンツ判定が門番をするため、候補プールの循環はバックテストの否定結果と矛盾しない。むしろ固定のままだと「同じ12銘柄しか見ない」という当初の問題が残る。
**決定**:
- `universe_rotator.py` を **apply=True** で週次実行。`rotation` 枠15銘柄をファクター採点で自動入れ替え(core 5銘柄は不変)。通知には「候補の入れ替えであり、シグナルはクオンツ判定通過分のみ」と明記。
- ヒステリシス状態(連続基準割れ週数)は `data/rotation_state.json`(CIランナーで毎回消える)をやめ、**watchlist項目の `strikes` フィールドとしてSupabaseに永続化**。
- `intraday_alert.yml` にもSupabase読み取り認証を追加し、3スキャナー全部が循環後の同一リストを見る。
**代替案**: 通知のみ運用(前エントリ) → 候補が固定化し当初の問題が残るため、位置づけを再定義した上で自動化を採用。
**見直す条件**: 循環枠由来のシグナル(channel=quant_scan のうち rotation 銘柄)の実測成績が数ヶ月見て core 銘柄由来より明確に悪ければ、循環ロジックを見直す。

## 2026-08-23 (位置づけ再定義済み・上記エントリ参照): フルバックテストの結果、apply=True は見送り — ローテーターは情報提供に徹する

**背景**: Lightプラン移行後、本番スコア式そのもの(5ファクター+レジーム適応+全ガード)を週次192地点・約3.9年でウォークフォワード検証した([[docs/experiments.md]]参照)。結果、本番設定はTOPIXに累積-38.5pt劣後。9通りのアブレーションでも対TOPIX週次勝率は49-53%に留まり、統計的なエッジは確認できなかった。
**決定**:
- `universe_rotator.py` は **apply=False(週次ドライラン通知)のまま恒久運用**。ファクター採点結果は「市場で今どの銘柄が強いか」の情報として毎週届くが、ウォッチリストの自動書き換えはしない。銘柄の入れ替えは通知を見た人間の判断で `/api/watchlist` から行う。
- 検証で作った資産(5年キャッシュ・full_backtest.py・アブレーション手法)は残す。新しいファクター仮説はコード変更なしで数分で検証できる。
- 前エントリの「本番反映を目指す」は、検証で反証されたため撤回。**これは検証プロセスが機能した結果**であり、検証せずに本番反映していたらTOPIX以下の自動売買推奨を毎週流していた。
**代替案**: 最良だったアブレーション構成(モメンタム単独+即入替、+160.8%)でapply=Trueにする案 → 9通り試した中の最良値であり多重比較バイアスの疑いが濃く、TOPIX+15pt/4年・勝率50%では根拠として弱すぎるため不採用。
**見直す条件**: (1) J-Quants Standard の需給データ(信用残・空売り)など**直交する新しいシグナル**を加えた構成で、対TOPIX勝率が有意水準で55%を超えたら再検討。(2) チャネル別実績集計(Phase 4)で数ヶ月の実運用データが貯まり、theme_ranking/quant_scanチャネルに実測エッジが見えたら、その知見をファクター側に還元して再検証。

## 2026-08-23 (撤回済み・上記エントリ参照): 「数ヶ月様子見」を撤回し、有料プラン+フルバックテストで本番反映を目指す

**背景**: 下記の「当面ドライランのまま数ヶ月運用」という決定は、オーナーの方針確認前に置かれた保守的判断だった。オーナーの意向は「待たずに前に進める。必要ならJ-Quants有料プランに移行する」。
**決定**: 以下の順で `apply=True`(ウォッチリストの自動循環を本番反映)を目指す:
1. J-Quants を **Light プラン**(月額約¥1,650: 遅延なし・60回/分・過去5年)に移行 ← オーナー操作待ち。
   実装済みの全機能とフルバックテスト(週次リバランスで検証地点200以上)はLightで足りる。
   Standard(+¥1,650: 信用残・空売り比率・財務詳細)は需給シグナルを実装する段階になったら、
   その価値を見て追加判断する(2026-08-23オーナー確認済み: 「Lightでやり、これも見たかったらStandard」)
2. 移行後、`factor_backtest.py` を本番スコア式そのもの(5ファクター+レジーム適応+急騰株ガード)・週次リバランス(n=26以上)に拡張して再検証
3. 結果が固定リスト・TOPIX比で妥当なら `apply=True` に切り替え
この間もPhase 3-4(レジーム適応・決算またぎ抑制・チャネル別実績集計・LLMカタリスト注記)の実装は先行して完了させる(2026-08-23実装済み)。
**代替案**: ドライラン通知を数ヶ月蓄積してから判断する案(下記エントリ)→ 検証速度が遅すぎるため撤回。
**見直す条件**: フルバックテストでローテーションが固定リストに明確に劣後したら、apply=True は見送り、ファクター構成を再設計する。

## 2026-08-23 (撤回済み・上記エントリ参照): universe_rotator は当面 apply=False(ドライラン)のまま運用する

**背景**: 週次ファクター循環の簡易バックテスト(11地点、[[docs/experiments.md]]参照)で固定リスト・TOPIXをわずかに上回ったが(+5.63% vs +4.83%/+4.89%、勝率64%)、n=11は統計的に有意とは言えない水準。かつ今回の検証はROE/PBR/vol_20dを含まない簡易版(momentum_12_1・ret_3mのみ)。
**決定**: `apply=True` への切り替えは保留し、`.github/workflows/universe_rotator.yml` は通知のみのドライランで継続する。J-Quantsの契約範囲(2024-06〜2026-05、約2年)は時間経過とともに伸びるため、より多くの検証地点・全ファクター込みでの再検証を待つ。
**代替案**: 平均リターンが上回っている点を根拠に今すぐapply=Trueにする案もあったが、下落局面(2026-02-09地点、ローテーション-5.8% vs 固定+1.7%)で固定リストより大きく負けており、下振れリスクの検証が不十分な状態で本番反映するのは時期尚早と判断。
**見直す条件**: (1) 実際の週次ドライラン通知を3ヶ月以上蓄積し明確な優位性が見えたら、または (2) J-Quants Standard以上に契約してROE/PBR/vol_20d込みの本番スコア式そのもので再バックテストし、統計的にもっと説得力のある結果(n=30以上目安)が出たら再検討する。

# バックテスト実験ログ

`modules/post_analysis/backtester.py`はスキャナーには組み込まれておらず、手動実行した結果はターミナルに出力されるだけで残らない。閾値やパラメータを調整する判断のもとになった実験は、ここに残す。

実行コマンド:
```bash
python modules/post_analysis/backtester.py TICKER --hold-days 5 --vol-multiplier 3.0
```

## テンプレート

```markdown
### YYYY-MM-DD: <何を試したか>

**コマンド**: 実際に実行したコマンド(パラメータ込み)
**対象**: どの銘柄・期間
**結果**: 勝率・平均リターンなど、出力された数値
**結論**: この結果を受けて何を変えた/変えなかったか(→ 恒久的な変更なら [[docs/decisions.md]] にも記録)
```

### 2026-08-23: universe_rotator(週次ファクター循環)の簡易ウォークフォワード検証

**コマンド**: `python modules/post_analysis/factor_backtest.py`(momentum_12_1 + ret_3m のみの軽量版。ROE/PBR/vol_20dは今回未使用 — 理由は下記)
**対象**: 東証プライム全銘柄、J-Quants Freeプランの契約範囲(2024-06-03〜2026-05-29、約2年)のうち検証可能な11地点(20営業日=約1ヶ月間隔でリバランス、各地点で先読み20営業日のリターンを評価)
**結果**:
| | 20営業日毎の平均リターン |
|---|---|
| ローテーション(モメンタム採点、循環枠15) | +5.63% |
| 固定12銘柄(現行ウォッチリスト) | +4.83% |
| TOPIX | +4.89% |

ローテーションが固定リストに勝った地点: 7/11(64%)。個別には2026-02-09地点で-5.8%(固定+1.7%、TOPIX-2.5%)と、下落局面で固定リストより大きく負ける地点もあった。

**結論**: 平均では固定リスト・TOPIXの両方を上回ったが、**n=11は統計的に「効果あり」と言うには全く足りない**(64%勝率はコイン投げの範囲内)。加えてこの検証はROE/PBR(quality/value)とvol_20d(低ボラ・急騰株ガード)を含まない簡易版 — J-Quants Freeプラン(5リクエスト/分)でのAPI予算制約のため、リバランス地点ごとに単一日オフセットだけで完結する2ファクター(momentum_12_1・ret_3m)に絞った。本番のスコア式(5ファクター合成)そのものの検証にはなっていない。よって `apply=True`(ウォッチリストへの自動反映)へは切り替えず、`universe_rotator.py`はドライラン(通知のみ)のまま継続する。実際の週次ドライラン結果を数ヶ月分蓄積して、簡易バックテストと合わせて判断材料にする方針。→ [[docs/decisions.md]] に恒久方針として記録済み。

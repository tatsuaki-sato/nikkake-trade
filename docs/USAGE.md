# 日々の使い方ガイド

nikkake-trade を「毎日どう使うか」をまとめたもの。仕様の詳細は [README.md](../README.md)、障害時の対応は [operations.md](operations.md)、設定変更の経緯は [decisions.md](decisions.md) を参照。

このツールは売買を実行しない。通知とダッシュボードは判断材料であり、実際に買うかどうか・いつ売るかは自分で決め、証券会社で発注する。

## 1日・1週間の流れ

| 時刻 (JST) | 自動で起きること | 自分がやること |
|---|---|---|
| 毎日 08:00 | 朝の予測 (`prediction.yml`) が通知される 🔮 | 寄り付き前に候補を確認し、買うなら注文を検討 |
| 平日 09:00〜15:55 | 5分おきに出来高急増をチェック (`intraday_alert.yml`)。条件を満たすと即時通知 🚨 | 通知が来たらチャートを見るだけ。飛びつかない |
| 毎日 15:30 | 大引け後の事後分析 (`daily_scanner.yml`) が通知される 🏛️ | 翌朝までに候補を確認。買ったものはポートフォリオに登録 |
| 土曜 10:00 | 週次の勝率レポート (`weekly_performance.yml`) 🏆 | どの経路のシグナルが当たっているかを確認 |
| 日曜 10:00 | ウォッチリストの入れ替え (`universe_rotator.yml`) 🔁 | 入れ替わった銘柄をざっと確認 |

`prediction` と `daily_scanner` の cron は土日も含めて毎日設定されている。休日の通知は前営業日のデータに基づくので、平日ほど重視しなくてよい。

通知は LINE に送られる(LINEのトークンが未設定の場合のみ Discord に送られる)。

## 通知の読み方

### 🔮 朝の予測 / 🏛️ 大引け後の分析 (シグナル通知)

どちらも同じ形式で、条件を満たした銘柄ごとに次の項目が並ぶ。

- **クオンツスコア**: 100点満点。朝は60点以上かつ「スクイーズ解除・強モメンタム・EDINET開示」のいずれか、大引け後は70点以上で通知される。
- **チャート**: TradingView へのリンク。
- **シミュレーション購入金額 (100株)**: 推奨時株価×100株。
- **配当利回り / 株主優待 / PER / PBR / EPS予想成長率**: 参考情報で、スコアには入っていない。
- **推奨損切りライン**: 終値 − 2×ATR。
- **目標価格 (利確)**: 終値 + 3×ATR。RR比はリスクリワード比。
- **【数理＆マクロ根拠】**: 何で点数が付いたか(モメンタム、スクイーズ、OBV、マクロ、EDINET 等)。

決算発表が近い銘柄は、スコアに関係なく自動で除外されている。

通知に載った銘柄は、自動で「AI推奨シグナル」として記録され(ステータス `OPEN`)、以後の値動きで勝敗が追跡される。

### 条件を満たす銘柄がなかった日の通知

「特定銘柄は検出されませんでしたが…」で始まり、株探の注目テーマ TOP3 と代表銘柄が並ぶ。これらもスコア65固定で自動記録されるが、クオンツ判定を通ったものではない。**実際に買う候補としての優先度は低い**と考える。

「⚠️ 株探ランキングの取得にも失敗したため…固定の参考リスト」と出た日は、市場の実勢を反映していないので読み流してよい(記録もされない)。

### 🚨 場中の急騰速報

直前の5分足に比べて出来高が10倍以上、かつ陽線の銘柄が出ると届く。シグナルとしては記録されない。

急騰の「速報」であって買いの推奨ではない。高値掴みになりやすいので、保有銘柄なら利確の判断材料に、未保有なら翌日以降の監視候補にする程度にとどめる。

### 🏆 土曜の週次レポート

- **通算対戦成績・勝率**: これまでのAIシグナル全体の成績(利確到達=勝ち、損切到達=負け)。
- **供給チャネル別成績**: 「日次クオンツ」「朝の予測」「ランキング経由」「手動追加」ごとの勝率。**どの経路のシグナルを信用するかは、ここで決める。**
- **直近AI推奨シグナル**と、登録してあれば実際の保有銘柄の損益。

### 🔁 日曜のウォッチリスト入れ替え

東証プライム全体をファクター採点し、ウォッチリストの `rotation` 枠(15銘柄)を入れ替える。`core` 枠(5銘柄)は変わらない。**自動で反映される**(通知に「✅ ウォッチリストに自動反映済み」と出る)。

- 📥 IN / 📤 OUT: 入った銘柄と外れた銘柄。INにはニュースから読んだ材料の有無(🟢/⚪/🔴)が付くことがある。
- ⚠️ 猶予中: 基準を割ったがまだ外れていない銘柄。2週連続で割るとOUT。
- リスクオフ判定の週は、新規INが止まる。

これは「スキャン対象の入れ替え」であって「買うリスト」ではない。ここに入っただけの銘柄は買わない。

## AIシグナルをどう判断するか

通知が来たら、次の順で見ると迷いにくい。

1. **経路を見る**: クオンツ判定を通った銘柄(スコア70点以上/朝の予測)か、ランキング経由のフォールバックか。後者は優先度を下げる。
2. **根拠を読む**: 【数理＆マクロ根拠】に複数の要素が並んでいるほうが強い。マクロだけ、センチメントだけで点が乗っている銘柄は慎重に。
3. **損切りラインまでの距離を確かめる**: 損切りラインで切られたときの損失額(100株なら (株価 − 損切りライン) × 100)が許容範囲か。許容できないなら株数を減らすか見送る。
4. **チャートを開く**: 直近で急騰しきっていないか、出来高を伴っているか。
5. **週次レポートの成績と照らす**: その経路の勝率が悪い時期は見送りを増やす。

買わないと決めたシグナルは、そのまま放置してよい(自動で勝敗が記録され、成績検証のデータになる)。ダッシュボード上で候補を整理したいときだけ削除する。

## ダッシュボードの使い方

Render にデプロイしたURLを開く(ローカルなら http://localhost:8000)。タブが2つある。

- **🤖 AI推奨シグナル** (`/candidates`)
  - 自動記録されたシグナルと、自分で追加した候補の一覧。ステータスは `OPEN 監視中` / `WIN 利確到達` / `LOSS 損切到達`。
  - 「損益の起点」で、登録時・前営業日・1週間前・1ヶ月前からの損益に切り替えられる。
  - 「➕ 画面から推奨候補銘柄を追加」で、自分で気になった銘柄を追加できる(週次レポートでは「手動追加」として集計される)。
  - チェックボックスで選んで一括削除、開始日時の一括変更ができる。
- **💼 My リアル購入ポートフォリオ** (`/portfolio`)
  - 実際に買った銘柄だけを登録する場所。

株価はページを開いたときに裏で更新される。すぐ最新にしたいときは右上の「🔄 データ再読み込み」を押す。

## 買った銘柄をポートフォリオに反映する

証券会社で約定したら、その日のうちに登録する。

1. 「💼 ポートフォリオ」タブを開き、「➕ 画面から購入銘柄を即時追加」を押す。
2. AIシグナルから買った場合は、上のドロップダウン「AI推奨候補から選択」で選ぶとコードと企業名が入る。
3. **購入日時**を入れる(入れるとその日の終値が買付単価に自動で入る)。
4. **買付単価**を実際の約定単価に上書きする。自動入力は終値なので、そのままだと損益がずれる。
5. **購入株数**を入れる(初期値は100株)。
6. 「画面に追加して保存」を押す。

登録すると、利確目安(買付単価×1.06)と損切り目安(×0.96)が自動で設定され、損益が追跡される。これはAIシグナルの ATR ベースのラインとは別物なので、実際の売りの判断にはAIシグナル側のラインや自分のルールを使う。

**売却したとき**は、その銘柄を「削除」する。売却価格や実現損益を記録する機能はまだないので、実現損益は証券会社の画面で確認する。

## やらなくてよいこと

- `dashboard.html` / `index.html` の手編集(毎回自動で作り直される)。
- 買わなかったシグナルの削除(成績検証のために残しておくほうがよい)。
- ウォッチリストの手動メンテナンス(`rotation` 枠は日曜に自動で入れ替わる。長期で見たい銘柄を足したいときだけ `POST /api/watchlist` に `{"ticker": "7203", "tier": "core"}` を送る。`tier` を省くと `rotation` 扱いになり、日曜に外される可能性がある)。

## こんなときは

- 通知の冒頭に「⚠️ Supabase接続エラーのためJSON保存にフォールバックしました」と出た: その回の記録が失われる可能性がある。[operations.md](operations.md) の Supabase の項を見る。
- 通知が来ない、Actions が落ちている: [operations.md](operations.md) を見る。
